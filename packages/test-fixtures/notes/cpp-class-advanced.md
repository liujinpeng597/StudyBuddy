# C++ 类进阶

## 问题：什么是继承？

继承让派生类在基类的公共接口和可复用实现之上扩展自己的行为。继承表达“是一种”的关系，也意味着派生类对象包含一个基类子对象。

```cpp
class Animal {
public:
    virtual ~Animal() = default;
    virtual void speak() const = 0;
};

class Dog : public Animal {
public:
    void speak() const override { /* ... */ }
};
```

## 问题：什么是虚函数和多态？

虚函数允许通过基类指针或引用调用时，根据对象的动态类型选择派生类实现。运行时多态依赖对象的动态类型，而不是指针的静态类型。

含有至少一个纯虚函数且没有完整实现的类通常是抽象类。抽象类不能直接创建对象，但可以作为接口使用。基类析构函数在有动态分配资源时通常应声明为虚函数，以避免通过基类指针删除派生对象时只执行基类析构。

## 问题：类基础和类进阶怎么联系？

类基础中的封装界定了对象的状态与操作，继承与虚函数则是在这个边界之上表达接口复用和运行时选择。学习进阶内容时仍然需要构造函数、析构函数和访问控制作为基础。

## 相近概念：重载、重写与隐藏

重载发生在同一作用域中，函数名相同而参数不同。重写发生在派生类与基类虚函数之间，要求签名兼容并可写 `override`。隐藏是派生类声明了同名成员导致的名称查找结果，不一定构成重写。
