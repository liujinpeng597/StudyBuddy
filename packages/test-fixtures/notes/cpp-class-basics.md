# C++ 类基础

## 问题：什么是 C++ 类？

C++ 类是把数据和对这些数据的操作封装在一起的用户自定义类型。类定义对象具有哪些数据成员，以及对象可以执行哪些成员函数。对象是类的一个具体实例。

```cpp
class Counter {
public:
    void add() { value_ += 1; }
    int value() const { return value_; }
private:
    int value_ = 0;
};
```

## 问题：构造函数和析构函数分别做什么？

构造函数在对象创建时运行，用来建立对象满足使用前提的状态。析构函数在对象生命周期结束时运行，用来释放构造函数或其他成员函数取得的资源。

对象的构造顺序通常是基类、成员、派生类自身；析构顺序与构造顺序大体相反。默认构造函数是不需要实参即可调用的构造函数。

## 问题：什么是封装？

封装是把内部状态和实现细节隐藏在类的边界内，只通过公开接口表达可使用的行为。它让调用者依赖稳定的接口，而不是依赖具体数据布局。

## 相近概念：类与结构体

`class` 和 `struct` 都能定义成员函数、构造函数和访问控制。常见差异是默认访问权限：`class` 默认为 `private`，`struct` 默认为 `public`。
